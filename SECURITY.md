# Aegisora Security Policy

## Responsible Disclosure

Please report suspected vulnerabilities privately.

Include:
- affected component
- reproduction steps
- impact
- relevant logs/evidence
- suggested mitigation where available

Do not publicly disclose an unresolved vulnerability before coordinated remediation.

## Security Scope

This policy covers the Aegisora repository, runtime security components and supported production services.

## Incident Handling

Security incidents are triaged, contained, investigated, remediated and documented.

## Security Claims

Aegisora does not claim compliance, certification, residency, encryption scope or security controls that have not been verified with current evidence.
