## First outreach order

Start with Trendyol, Profound, and Clay for discovery because the public signals mention operational workflows that can be narrowed without starting with sensitive health data. Treat Persona, Doctolib, and Vanta as higher-bar technical/security design-partner candidates.

For each account, find the actual workflow owner and a security reviewer; validate whether a pre-action HTTP check can be inserted; ask about an isolated non-production test. Do not claim these companies need Aegisora, do not imply a relationship, and do not use customer-specific data or logos without written approval.
