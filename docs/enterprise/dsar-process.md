# GDPR Data Access / Deletion Request Process

Status: Operational draft.

## Intake

Record:
- requester
- request type
- received date
- identity-verification status
- deadline

## Verification

Verify identity before disclosure.

## Search

Check:
- authentication records
- account data
- workspace data
- audit/evidence
- support records
- billing records
- relevant subprocessors

## Fulfillment

Access:
- export applicable data

Deletion:
- delete where legally/contractually required
- document required exceptions

## Closure

Record systems checked, completion date and exceptions.
