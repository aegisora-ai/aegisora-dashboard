# Aegisora Enterprise Readiness

This directory contains evidence, runbooks and customer/investor diligence material.

## Status model

- PASS = verified by executable test or authoritative evidence
- FAIL = explicitly missing/broken
- NOT_VERIFIED = implementation may exist but evidence is incomplete
- BLOCKED = requires external system, credentials, customer action or legal review

Never convert NOT_VERIFIED or BLOCKED to PASS manually.
