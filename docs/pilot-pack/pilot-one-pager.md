# Aegisora - Design Partner Pilot (one page)

## What it is
A runtime governance layer for AI agents. It evaluates an agent's tool call before execution and returns ALLOW, BLOCK or ESCALATE (human review), and records each decision as evidence.

## What works today
- Open-source runtime (MIT license)
- Authenticated web console: agents, policies, API keys, approvals, decision and evidence records
- Live evaluation API with API-key authentication
- Role-based workspace access

## What the pilot is
A scoped, non-production evaluation of one customer-owned agent workflow, using synthetic or approved low-risk data, for a fixed period, with weekly check-ins. Setup is handled together with the founder.

## What we ask from you
- One agent workflow and one technical contact
- Honest feedback on false blocks, missing policies and missing integrations

## What we do not claim
- No SLA or uptime guarantee
- No compliance certification (SOC 2 is a roadmap item, not achieved)
- No production-readiness commitment yet
- Evidence records are designed to be tamper-evident
