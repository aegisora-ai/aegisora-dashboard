# Demo recording checklist (screen recording, 3-5 minutes)

Use a test workspace and synthetic data only. Never show real keys, emails or customer data.

1. Open https://www.aegisora.org and log in to the console.
2. Show the agents page and one registered agent.
3. Show one policy and what it allows and blocks.
4. Send an evaluation request that returns ALLOW (show the response).
5. Send a request that returns BLOCK (show the reason).
6. Send a request that returns ESCALATE and open the approval in the console.
7. Approve or reject it and show the decision record.
8. Open the evidence page and show the record for that decision.
9. Close with the one-page pilot scope (what works, what is not claimed).

After recording: watch it once and blur or cut anything that shows keys, tokens or personal data.
