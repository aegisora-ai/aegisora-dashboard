# Aegisora Website4 — Open Source UI Stack

This project intentionally uses open-source building blocks instead of
copying a commercial SaaS template.

## UI / accessibility
- shadcn/ui
  https://github.com/shadcn-ui/ui
  MIT

- Radix Primitives
  https://github.com/radix-ui/primitives
  MIT

## Icons
- Lucide
  https://github.com/lucide-icons/lucide
  ISC

## Motion
- Motion
  https://github.com/motiondivision/motion
  MIT

- Magic UI
  https://github.com/magicuidesign/magicui
  MIT
  Used as visual/reference inspiration and copy/paste-compatible patterns.

## Data / dashboards
- TanStack Table
  https://github.com/TanStack/table
  MIT

- Recharts
  https://github.com/recharts/recharts

## Forms / validation
- React Hook Form
  https://github.com/react-hook-form/react-hook-form
  MIT

- Zod
  https://github.com/colinhacks/zod
  MIT

## Notifications
- Sonner
  https://github.com/emilkowalski/sonner
  MIT

Aegisora's visual language is authored separately:
deep navy, blue/cyan execution boundary, evidence-led data surfaces,
thin technical lines, high-density enterprise information architecture,
minimal decoration and no fabricated customer claims.
